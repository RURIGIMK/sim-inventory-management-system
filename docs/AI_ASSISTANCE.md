# AI Assistance and Development Tools

## Transparency

AI-assisted development may be used for planning, documentation, code explanation, debugging assistance and review. AI assistance does not replace understanding or verification of the resulting implementation.

For academic defense, only tools actually used during development should be named.

## Recommended Disclosure

If asked whether an AI coding assistant was used, give an accurate account of the tools used and the tasks for which they were used. Do not claim that an AI agent implemented functionality unless the repository history and development record support that claim.

A suitable statement when applicable is:

"AI assistance was used selectively for planning, documentation, code review and debugging support. The resulting code was reviewed, tested and understood by the developer."

## Repository Policy

Generated or suggested code should be reviewed before committing. Secrets, credentials, personal data and unverified external content must not be copied into the repository.

## Defense Preparation

Be prepared to explain every important module without relying on the AI assistant. The key evidence is the source code, Git history, tests and the working application.
